# Treino – app da ficha atual

App web (um único `index.html`) para acompanhar a ficha de treino pelo celular.

Acesse: https://edipoalex.github.io/treino/ e use **Adicionar à tela inicial**.

## Nova ficha
Só o objeto `FICHA` dentro do `index.html` muda. Histórico, cargas e ajustes ficam salvos
no navegador, separados por número de etapa, então trocar a ficha não apaga o histórico anterior.

## Backup
Os dados ficam no navegador do aparelho. Use **Ajustes › Exportar** de vez em quando.
